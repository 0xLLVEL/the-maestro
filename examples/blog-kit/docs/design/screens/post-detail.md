# Screen: post-detail

Single published post with author and date. Reuses post-card. New: post-body.
Skeleton, plain tags, no styling.

## Default

```html
<main>
  <article>
    <h1><!-- post title --></h1>
    <p><!-- author and date --></p>
    <div><!-- post body --></div>
  </article>
</main>
```

## Error (not found)

```html
<main>
  <h1>404</h1>
  <p><!-- post not found --></p>
</main>
```
